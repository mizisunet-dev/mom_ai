# 논술 시간표 (겹침 없는 수시 6장 짜기)

## 이 스킬이 푸는 문제

수시는 6장이다. 그런데 논술 시험일은 **수능 직후 2~3주의 주말에 몰린다.**
그래서 실제로 벌어지는 사고는 두 가지다.

1. **시간 겹침** — 원서를 넣고 나서야 두 대학이 같은 날 같은 시간인 걸 안다. 한 장을 그냥 버린다.
2. **이동 실패** — 시간은 안 겹치는데, 오전 수원 → 오후 서울 이동이 물리적으로 불가능하다.
   시험은 시작 시각이 아니라 **입실 마감**이 기준이라 30~40분을 더 빼야 한다.

이 스킬은 두 번째까지 계산한다. 원서접수 **전에** 돌리는 게 핵심이다.

## 작업 순서

### 1단계 — 후보를 CSV로 모은다

`templates/candidates.sample.csv` 를 복사해 작업 파일을 만든다.
사용자의 실제 데이터는 `mom-mode/` 아래에 연도별로 둔다 (예: `mom-mode/2027-논술후보.csv`).

| 열 | 내용 | 비고 |
|---|---|---|
| `id` | 식별자 | 비우면 자동 부여 |
| `대학` / `모집단위` / `전형` | 대학명, 학과, 전형명 | |
| `날짜` | `2026-11-21` | **YYYY-MM-DD 고정** |
| `시작` / `종료` | `14:00` | `종료`가 비면 `--duration`(기본 120분)으로 계산 |
| `입실` | `12:30` | **입실 마감 시각. 모집요강에 있으면 반드시 채운다** — 비면 `시작 - --buffer`로 가정 |
| `고사장` | 건물명 등 | 출력·캘린더에 표시 |
| `권역` | `서울성북`, `경기수원`, `대전유성` | **이동시간 추정의 유일한 근거. 반드시 채운다** |
| `수능최저` | 최저 있는 전형이면 `Y` | |
| `최저충족` | `Y` / `N` / `?` | `수능최저=Y` + `최저충족=N` 은 기본 제외 |
| `선호도` | 1~5 (5가 최우선) | 조합 랭킹 기준 |
| `메모` | 자유 | |

날짜를 찾을 때: **각 대학 입학처의 최종 모집요강 PDF가 유일한 정답**이다.
입시 커뮤니티·블로그 요약본은 변경 전 일정인 경우가 많다. WebSearch로 후보를 좁히더라도
확정 전에는 대학별 입학처 페이지에서 날짜·입실시각을 한 번 더 대조하고,
CSV `메모` 열에 확인한 날짜를 적어 둔다.

### 2단계 — 충돌 검사와 조합 탐색

```bash
python3 .claude/skills/nonsul-timetable/scripts/solve.py mom-mode/2027-논술후보.csv --top 5
```

주요 옵션:

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--slots N` | 지원 가능 카드 수 | 6 |
| `--buffer N` | `입실` 열이 빈 경우에만 쓰는 기본 입실여유(분) | 40 |
| `--duration N` | `종료` 미기재 시 시험 길이(분) | 120 |
| `--max-per-day N` | 하루 최대 응시 수. `1` 이면 "하루 한 개만" | 3 |
| `--max-per-univ N` | 같은 대학 최대 지원 수 (0=무제한) | 0 |
| `--must C5,C8` | 반드시 포함할 후보 (id 또는 대학명). 서로 충돌하면 이유를 알려주고 멈춤 | — |
| `--allow-miss` | 수능최저 미충족(N) 후보도 포함 | 꺼짐 |
| `--travel FILE` | 이동시간 직접 지정 CSV (`from,to,minutes`) | — |
| `--ics FILE` | 1순위 조합을 캘린더 파일로 저장 | — |
| `--sample` | 동봉 샘플로 시연 | — |

출력은 ① 제외된 후보 ② 전체 후보 목록 ③ **충돌 쌍**(시간겹침 / 이동불가) ④ 빠듯하거나 연속일 장거리인 구간 주의
⑤ 추천 조합 Top-N 을 날짜별 타임라인으로 보여준다.

### 3단계 — 사람이 판단하도록 정리해서 보고한다

숫자만 던지지 말고 이렇게 정리한다.

- **버려지는 카드**: 겹침 때문에 포기해야 하는 대학과, 그 대신 살아나는 대학
- **빠듯한 날**: 남는 여유가 45분 미만이면 교통편 사전 확정 대상, 20분 미만이면 권하지 않는다고 명시
- **입실 마감이 미확인인 곳**: 그 값 하나로 조합이 갈리는 경우가 있다. 몇 시 이후여야 가능한지를
  분 단위로 계산해 "이 시각까지 도착 가능해야 함"으로 알려준다
- **수능 전/후 구분**: 수능 전 논술은 수능 대비 흐름을 끊는다. 감수하고 넣을지 사용자에게 확인
- **남는 카드**: 6장을 논술로 다 채울 필요는 없다. 남으면 교과/학생부/실기로 채우라고 안내
- 마지막에 **"최종 확정 전 각 대학 모집요강 재확인"** 을 반드시 덧붙인다

### 4단계 — 캘린더에 넣는다 (선택)

`--ics` 로 파일을 만들면 입실여유가 반영된 시작 시각과 하루 전 알림이 함께 들어간다.
Google Calendar MCP를 쓸 수 있으면 `create_event` 로 직접 등록해도 된다.
이때도 **시작 시각은 시험 시작이 아니라 입실 마감 기준**으로 넣는다.

## 이동시간 추정에 대해

`권역` 문자열에서 광역권(서울/경기/인천/충청/영남/호남/강원/제주)을 추정해 표에서 찾는다.
같은 권역 문자열이면 40분, 서울 안이면 60분, 서울↔경기 90분 같은 **보수적 추정치**다.

이 값은 실제 교통을 모른다. 아래 경우엔 반드시 `--travel` 로 실측값을 덮어쓴다.

- 같은 서울이어도 강북 ↔ 강남처럼 대각선으로 가로지르는 경우
- 자차 이동인데 시험 당일 고사장 주차가 통제되는 경우
- KTX/SRT 시간표에 묶여 있어 배차 간격이 실제 제약인 경우

```csv
from,to,minutes
서울성북,경기수원,105
서울마포,서울성북,55
```

## 재활용

이 스킬은 논술 전용이 아니다. **날짜·시간·장소가 있고 개수 제한이 있는 모든 선택 문제**에 쓴다.

- 영화과 등 예체능 **실기·면접 일정** (실기는 3~4시간짜리라 하루 두 개가 거의 불가능 — 충돌이 더 잘 난다)
- 정시 면접·실기 일정
- 형제가 둘이면 **각자 CSV를 따로 만들고**, 학부모 인솔이 필요한 날이 겹치는지는 두 결과의 날짜를 대조해 확인한다

## 하지 말 것

- 시험 날짜를 **기억이나 추측으로 채우지 않는다.** 출처 없는 날짜는 CSV에 넣지 말고 사용자에게 확인받는다.
- 합격 가능성을 예측하지 않는다. 이 스킬이 다루는 건 **일정 충돌**뿐이다. `선호도`는 사용자가 정한다.
- 원서접수 마감 임박이라고 조합을 임의로 확정하지 않는다. 최종 선택은 항상 사용자가 한다.
