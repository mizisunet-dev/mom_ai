# 논술 시간표 — 겹치지 않는 수시 6장 짜기

수시는 6장인데, 논술 시험일은 수능 직후 2~3주의 주말에 전부 몰립니다.
그래서 해마다 같은 사고가 납니다.

1. **시간 겹침** — 원서를 넣고 나서야 두 대학이 같은 날 같은 시간인 걸 압니다. 한 장을 그냥 버립니다.
2. **이동 실패** — 시간은 안 겹치는데, 오전 시험 끝나고 오후 고사장까지 도착이 불가능합니다.
   시험 기준은 시작 시각이 아니라 **입실 마감**이라 30~40분을 더 빼야 합니다.

엑셀로 날짜만 비교하면 1번은 잡히지만 **2번은 안 잡힙니다.**
이 도구는 2번까지 계산해서, 실제로 응시 가능한 조합만 남깁니다.

> ⚠️ **이 도구는 일정 충돌만 계산합니다.** 합격 가능성을 예측하지 않고, 시험 날짜를 대신 찾아주지도
> 않습니다. 날짜는 **각 대학 입학처의 최종 모집요강**에서 직접 확인해 넣으셔야 합니다.

---

## 실제로 이런 걸 잡아냅니다

```
[충돌 — 동시 지원 불가]
  ✕ 시간겹침  고려대 식품자원경제학과  ↔  동국대 경영대학(광역)   (11/22)
              시험 시간이 80분 겹칩니다
  ✕ 이동불가  동국대 경영대학(광역)  ↔  경희대 Hospitality경영학과   (11/22)
              14:40 종료 → 14:20 (경희대 시작 40분 전)까지 -20분뿐인데
              이동에 35분 필요 — 55분 부족
  ✕ 이동불가  한국외대 국제통상학과(글로벌)  ↔  한양대 관광학부   (11/28)
              16:30 종료 → 16:20 (한양대 시작 40분 전)까지 -10분뿐인데
              이동에 100분 필요 — 110분 부족
```

시간표만 봐서는 "안 겹치네" 하고 넘어갈 조합들입니다.

## 3단계로 끝

### 1단계 · 어떻게 생겼는지 먼저 보기

```bash
python3 scripts/solve.py --sample
```

가상의 대학 데이터로 한번 돌아갑니다. 출력이 어떻게 나오는지 보고 시작하세요.

### 2단계 · 우리 아이 후보를 표로 만들기

`templates/candidates.sample.csv` 를 복사해서 엑셀로 열고, 내용을 바꿔 저장합니다.
저장할 때 **"CSV UTF-8"** 형식을 고르세요.

| 열 | 뭘 적나 | 필수 |
|---|---|:---:|
| `id` | 아무 이름표 (K1, K2 …). 비워도 자동으로 붙습니다 | |
| `대학` | 고려대, 성균관대 … | ✅ |
| `모집단위` | 경영학과, 국제무역학과 … | |
| `전형` | 논술100% 100분 … | |
| `날짜` | `2026-11-21` — **반드시 이 형식** | ✅ |
| `시작` / `종료` | `13:00` / `14:40` | ✅ / |
| `입실` | 입실 마감 시각. 모집요강에 있으면 꼭 적으세요 | |
| `고사장` | 인문사회과학캠퍼스 … | |
| `권역` | `서울성북`, `경기용인` — **이동시간 계산의 근거** | ✅ |
| `수능최저` | 최저 있는 전형이면 `Y` | |
| `최저충족` | 충족할 것 같으면 `Y`, 아니면 `N`, 모르면 `?` | |
| `선호도` | 1~5. 5가 가장 가고 싶은 곳 | |
| `메모` | 경쟁률, 모집인원, 확인한 날짜 등 | |

`입실`을 비우면 "시작 40분 전"으로 가정합니다. **모집요강에 입실 마감이 적혀 있다면 꼭 넣으세요.**
이 한 칸이 조합 결과를 바꿉니다.

### 3단계 · 돌리기

```bash
python3 scripts/solve.py 우리아이후보.csv --top 5
```

끝입니다. 충돌 쌍과 추천 조합이 날짜별 시간표로 나옵니다.

## 상황별 옵션

| 하고 싶은 것 | 이렇게 |
|---|---|
| 꼭 넣어야 할 대학이 있다 | `--must K5,K8` |
| 하루에 한 개만 보겠다 | `--max-per-day 1` |
| 최저 못 맞출 것 같은 곳도 일단 보겠다 | `--allow-miss` |
| 캘린더에 넣겠다 | `--ics 논술.ics` → 구글/애플 캘린더에서 가져오기 |
| 이동시간을 실제 값으로 넣겠다 | `--travel 이동시간.csv` |
| 지원 횟수가 6장이 아니다 | `--slots 3` |

### 이동시간을 직접 넣기

기본값은 권역만 보고 어림잡습니다(서울 안 60분, 서울↔경기 90분 등).
**같은 서울이어도 강북에서 강남은 훨씬 오래 걸립니다.** 그런 구간은 직접 넣으세요.

`이동시간.csv`:

```csv
from,to,minutes
서울성북,서울동대문,25
서울중구,서울마포,35
경기용인,서울성동,100
```

지도 앱에서 **시험 당일 요일·시간대로** 검색한 값을 쓰는 게 가장 정확합니다.

## 논술 말고도 씁니다

날짜·시간·장소가 있고 **개수 제한이 있는** 모든 선택 문제에 그대로 쓸 수 있습니다.

- **예체능 실기·면접** — 실기는 3~4시간짜리라 하루 두 개가 거의 불가능해서 충돌이 훨씬 잘 납니다
- **정시 면접·실기**
- **아이가 둘이면** 각자 파일을 따로 만들고, 부모가 같이 가야 하는 날이 겹치는지 두 결과를 대조하세요

## 이건 못 합니다 (그리고 안 합니다)

- **시험 날짜를 찾아주지 않습니다.** 추측으로 채우면 안 되는 데이터라서 일부러 넣지 않았습니다.
- **합격 가능성을 예측하지 않습니다.** `선호도`는 부모와 아이가 정하는 값입니다.
- **원서를 대신 넣지 않습니다.** 최종 선택은 항상 사람이 합니다.

이동시간은 어디까지나 추정치입니다. **확정 전에 실제 교통편으로 한 번 더 확인하세요.**
시험일·입실시각·고사장은 최종 모집요강과 수험표가 유일한 정답입니다.
