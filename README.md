# 단장(丹粧) — 나 대신 입어주는 AI 피팅룸 · ver2

사고 싶은 옷의 **실제 쇼핑몰 링크를 붙여넣으면**, 서버가 상품 페이지를 읽어
사이즈 실측표·품절 정보를 추출하고, 내 치수로 만든 **마네킹이 대신 입어보고**
사이즈가 맞는지 판정해주는 모바일 웹앱입니다.

화이트톤 바탕에 한국 전통 **단청 팔레트**(석록·석간주·군청·황)를 포인트로 사용했습니다.

## 실행 방법

```bash
npm install
npm start                       # http://localhost:3000

# (선택) AI 폴백 추출 활성화 — 구조가 특이한 페이지를 Claude가 읽어줌
ANTHROPIC_API_KEY=sk-ant-... npm start
```

모바일 브라우저(또는 데스크톱 모바일 모드)에서 접속하세요.

## ver2에서 새로 된 것: 실제 쇼핑몰 링크 지원

```
링크 붙여넣기
  → 서버가 상품 페이지 fetch (모바일 UA, 12초 타임아웃, 3MB 제한)
  → 1차: 휴리스틱 파서 (lib/extract.js)
      · JSON-LD(schema.org/Product) / OpenGraph → 상품명·브랜드·가격·품절
      · HTML 표 스캔 → 사이즈 실측표 (가로형·세로형 모두, 점수화해 최적 표 선택)
      · 가슴둘레 96cm ↔ 가슴단면 48cm 자동 판별·정규화
      · 사이즈 옵션 영역에서 "품절/SOLD OUT" 사이즈 감지
      · 원단 텍스트로 신축성 추정 (스판덱스/니트/논스판…)
  → 2차: 1차 실패 시 Claude(claude-opus-4-8) 구조화 추출 (API 키 있을 때만)
  → 실패 시: 데모 카탈로그로 대체 분석 + 화면에 사유 표시
```

- 결과 화면에 **분석 출처**가 표시됩니다: `✓ 실제 상품 페이지` / `AI 추출` / `⚠ 데모 대체 분석`
- 실상품이 안 맞거나 품절이면 **네이버쇼핑/무신사 검색 링크**로 대체상품을 찾고,
  찾은 링크를 다시 붙여넣으면 즉시 실측 판정해줍니다.

## 전체 기능

| 기능 | 설명 |
|---|---|
| 신체 사이즈 온보딩 | 키·몸무게·어깨·가슴·허리·엉덩이·팔길이·안기장. 모르면 키·몸무게로 자동 추정 |
| 핏 취향 | 타이트 / 정사이즈 / 박시 — 판정 기준이 취향에 맞춰 바뀜 |
| 내 마네킹 | 실측에 비례해 그려지는 SVG 마네킹 + 제품 실측 비율 그대로 착용 |
| 사이즈 판정 | 부위별 여유량(cm)·신축성 반영. **"같은 M인데 작게 나온 제품"을 표준 실측표(S/M/L·90호대·44/55/66)와 비교해 감지** |
| 품절/불일치 대응 | 최적 사이즈 품절 시 차선 추천+안내, 안 맞으면 대체상품 검색 |
| 최근 기록 | 입어본 옷·판정 결과 저장(localStorage), 탭하면 재분석 |

## 테스트

목(mock) 쇼핑몰(실제 쇼핑몰과 동일한 페이지 구조)로 파이프라인을 검증합니다:

```bash
node test/mock-shop.js &                      # :8899 — 니트(둘레표기·품절)/데님(전치표)/표없음
DANJANG_ALLOW_PRIVATE=1 npm start             # 로컬 목샵 허용 모드
# 앱에서 http://localhost:8899/product/knit-round 붙여넣기
```

## 한계와 ver3 로드맵

- **JS 렌더링 SPA 몰**(지그재그·에이블리 등 일부): 서버 fetch만으로는 HTML에 데이터가 없어
  실패할 수 있음 → ver3에서 헤드리스 브라우저 렌더링 추가 예정
- **이미지로만 올라온 사이즈표**: 텍스트 추출 불가 → ver3에서 Claude 비전으로 이미지 판독 예정
- **봇 차단이 강한 몰**: 접속 실패 시 데모 대체 분석으로 안내됨
- 대체상품을 검색 링크가 아닌 **실시간 커머스 API 검색 결과**로 확장
