# 단장(丹粧) — 나 대신 입어주는 AI 피팅룸 · ver1

사고 싶은 옷의 **링크만 붙여넣으면**, 내 치수로 만든 **마네킹이 대신 입어보고**
사이즈가 맞는지 판정해주는 모바일 웹앱입니다.

화이트톤 바탕에 한국 전통 **단청 팔레트**(석록·석간주·군청·황)를 포인트로 사용했습니다.

## 실행 방법

빌드 없이 정적 파일만으로 동작합니다.

```bash
# 아무 정적 서버로 열면 됩니다
python3 -m http.server 8000
# → 모바일 브라우저(또는 데스크톱 브라우저 모바일 모드)에서 http://localhost:8000 접속
```

## ver1 기능

| 기능 | 설명 |
|---|---|
| 신체 사이즈 온보딩 | 키·몸무게·어깨·가슴·허리·엉덩이·팔길이·안기장 입력. 모르면 키·몸무게로 자동 추정 |
| 핏 취향 | 타이트 / 정사이즈 / 박시 — 사이즈 판정 기준이 취향에 맞춰 바뀜 |
| 내 마네킹 | 입력한 실측에 비례해 그려지는 SVG 마네킹 |
| 링크 피팅 | 상품 링크 붙여넣기 → 사이즈 차트 분석 → 마네킹에 실측 비율 그대로 착용 |
| 사이즈 판정 | 부위별 여유량(cm) 계산, 원단 신축성 반영. **"같은 M인데 작게 나온 제품"도 표준 실측과 비교해 감지** |
| 품절/불일치 대응 | 맞는 사이즈가 없거나 품절이면 같은 카테고리에서 재고 있는 **대체상품 자동 추천** |
| 최근 기록 | 입어본 옷과 판정 결과를 기기에 저장(localStorage) |

## 판정 엔진 개요 (`js/fit.js`)

1. 제품 실측(단면 ×2 = 둘레)과 사용자 둘레를 부위별로 비교해 **여유량(ease)** 계산
2. 핏 취향별 적정 여유 범위와 대조 — 예: 가슴 여유가 타이트는 2~8cm, 박시는 16~30cm
3. 원단 신축성(stretch)만큼 "작은 쪽" 허용치를 완화 (니트·밴딩은 관대하게)
4. 범위 이탈량을 감점해 사이즈별 0~100점 → 잘 맞아요 / 딱 붙어요 / 여유 있어요 / 작아요 / 커요
5. 브랜드 치수를 표준 실측표와 비교해 **"표기보다 평균 Ncm 작게/크게 나옴"** 안내
6. 최고점 사이즈가 품절이거나 60점 미만이면 → 대체상품 검색

## ver1 제약 및 ver2 로드맵

- **실제 쇼핑몰 크롤링 미지원**: 브라우저 단독으로는 타 사이트 접근(CORS)이 막혀 있어,
  ver1은 실제 쇼핑몰과 동일한 구조의 사이즈 차트를 가진 **내장 데모 카탈로그 12종**에
  링크를 키워드 매칭해 판정 엔진을 검증합니다. 미등록 링크는 데모 상품으로 대체 분석되며 화면에 표시됩니다.
- **ver2 계획**
  - 서버 프록시 + LLM 파싱으로 실제 상품 페이지에서 사이즈 차트·품절 정보 추출
  - 무신사/지그재그/에이블리 등 주요 몰 어댑터
  - 대체상품을 실제 커머스 검색 API로 확장
  - 마네킹 고도화(체형 프리셋, 3D)

```
js/mannequin.js   실측 비례 마네킹 + 의상 오버레이 SVG 렌더러
js/app.js         화면 흐름 · 상태 관리
```
