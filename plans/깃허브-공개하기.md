# 논술 시간표를 GitHub에 공개하기

다른 학부모가 쓸 수 있게 이 도구를 인터넷에 올리는 방법입니다.
**A안(웹 화면)과 B안(명령어) 중 하나만 하시면 됩니다.** A안이 훨씬 쉽습니다.

---

## 먼저 결정할 두 가지

### 1. 어디에 올릴까

| | 장점 | 단점 |
|---|---|---|
| **새 저장소를 만든다** ✅ 권장 | 도구만 깔끔하게 공개. 개인 파일(아이 입시 자료)이 안 섞임 | 저장소를 하나 더 관리 |
| 지금 `mom_ai` 저장소를 공개한다 | 할 일 없음 | **아이 입시 자료·회사 관련 내용이 전부 공개됩니다. 권하지 않습니다** |

`mom_ai` 에는 `mom-mode/` 아래 아이 지원 대학·경쟁률·수험번호까지 들어 있습니다.
**이 저장소는 비공개로 두세요.** 도구만 따로 떼어 새 저장소로 올립니다.

### 2. 저장소 이름

`nonsul-timetable` 을 권합니다. 한글 이름도 되지만 git 명령에서 다루기 번거롭습니다.
설명(Description)은 한글로 넣으면 됩니다:
> 수시 논술·실기 일정 충돌 검사 — 이동시간과 입실 마감까지 계산해 겹치지 않는 6장을 짜는 도구

## 준비 — 올릴 폴더 만들기

이미 만들어 두는 스크립트가 있습니다. 명령창에서 `mom_ai` 폴더로 간 뒤:

```bash
bash .claude/skills/nonsul-timetable/tools/make-standalone.sh
```

`~/nonsul-timetable` (내 홈 폴더 아래) 에 올릴 준비가 끝난 폴더가 생깁니다.
안에는 이것만 들어 있습니다 — **아이 입시 자료는 들어가지 않습니다.**

```
nonsul-timetable/
├── README.md                    ← GitHub 첫 화면에 보이는 설명
├── SKILL.md                     ← Claude Code 스킬 정의
├── LICENSE                      ← MIT (자유롭게 쓰고 나눠도 됨)
├── 논술시간표-사용설명서.pdf
├── scripts/solve.py             ← 프로그램 본체
└── templates/candidates.sample.csv
```

잘 만들어졌는지 한 번 돌려 보세요:

```bash
cd ~/nonsul-timetable
python3 scripts/solve.py --sample
```

## A안 · 웹 화면으로 올리기 (권장)

명령어를 몰라도 됩니다. 마우스로 끌어다 놓으면 끝납니다.

### 1단계 — 빈 저장소 만들기

1. [github.com/new](https://github.com/new) 접속
2. **Repository name** 에 `nonsul-timetable` 입력
3. **Description** 에 위의 한 줄 설명 입력
4. **Public** 선택 ← 다른 사람이 보려면 이것
5. 아래 **"Add a README file" 체크는 해제**한 채로
6. **Create repository** 클릭

### 2단계 — 파일 끌어다 놓기

저장소를 만들면 안내 화면이 나옵니다. 거기서
**"uploading an existing file"** 링크를 클릭하세요.
(또는 주소창에 직접: `github.com/내계정/nonsul-timetable/upload/main`)

그 다음 **탐색기(Finder)에서 `nonsul-timetable` 폴더를 열고,
그 안의 내용물 전체를 브라우저 화면에 끌어다 놓습니다.**

> ⚠️ **폴더 자체가 아니라 폴더 "안의 것들"** 을 끌어다 놓으세요.
> 폴더째 놓으면 `nonsul-timetable/nonsul-timetable/...` 처럼 한 겹 더 들어갑니다.
> 올린 뒤 화면에 `README.md`, `scripts`, `templates` 가 보이면 맞게 된 겁니다.

### 3단계 — 저장

화면 아래 **Commit changes** 버튼을 누릅니다. 끝입니다.

`https://github.com/내계정/nonsul-timetable` 주소를 다른 분께 보내면 됩니다.

## B안 · 명령어로 올리기

git을 써 보셨다면 이쪽이 빠릅니다.

### 1단계 — 빈 저장소 만들기

A안 1단계와 같습니다. **"Add a README file" 체크 해제** 가 중요합니다.

### 2단계 — 올리기

```bash
cd ~/nonsul-timetable

git init -b main
git add .
git commit -m "논술 시간표 첫 공개"

git remote add origin https://github.com/내계정/nonsul-timetable.git
git push -u origin main
```

`내계정` 부분만 본인 GitHub 아이디로 바꾸면 됩니다.

**비밀번호를 물어보면** GitHub 비밀번호가 아니라 **토큰**이 필요합니다.
[github.com/settings/tokens](https://github.com/settings/tokens) →
*Generate new token (classic)* → `repo` 체크 → 생성된 긴 문자열을 비밀번호 자리에 붙여넣기.
(한 번 설정하면 그 다음부터는 안 물어봅니다.)

## 올린 다음 — 다듬기

여기까지가 필수, 아래는 있으면 좋은 것들입니다.

### 저장소 첫 화면 정리

저장소 페이지 오른쪽 **About** 옆 톱니바퀴를 눌러 설명과 주제어를 넣습니다.
검색으로 찾아오게 하는 단어들:

```
korean-college-admission  논술  수시  입시  scheduling  timetable  conflict-detection
```

### 다른 분이 쓰는 법 안내

README에 이미 다 있습니다. 링크를 보낼 때 이 한 줄만 덧붙이면 충분합니다.

> 파이썬만 있으면 되고, 설치할 건 없어요. 내려받아서 `python3 scripts/solve.py --sample`
> 한 번 쳐 보시면 어떻게 생겼는지 바로 보입니다. 인쇄용 설명서 PDF도 같이 들어 있어요.

### 나중에 고친 내용 반영하기

`mom_ai` 쪽 스킬을 고쳤다면, 다시 내보내서 올리면 됩니다.

```bash
rm -rf ~/nonsul-timetable-new
bash .claude/skills/nonsul-timetable/tools/make-standalone.sh ~/nonsul-timetable-new

cp -R ~/nonsul-timetable-new/* ~/nonsul-timetable/
cd ~/nonsul-timetable
git add . && git commit -m "이동시간 계산 개선" && git push
```

## 공개하기 전 확인할 것

한 번 올린 파일은 나중에 지워도 **기록(커밋 히스토리)에는 남습니다.**
공개 버튼을 누르기 전에 이것만 확인하세요.

- [ ] 올릴 폴더에 아이 이름·학교·수험번호·성적이 **없다**
- [ ] `templates/candidates.sample.csv` 의 대학명이 **가상 이름**인지 확인
      (한빛대·가온대·도담대… 실제 대학이 아닙니다. 우리 아이 실제 데이터로 덮어쓰지 마세요)
- [ ] 개인 연락처·이메일이 README에 없다
- [ ] `mom-mode/` 폴더는 **애초에 복사되지 않습니다** — 스크립트가 도구만 가져옵니다

마지막 항목 때문에 `make-standalone.sh` 를 쓰는 겁니다.
손으로 폴더를 복사하면 실수로 개인 파일이 섞일 수 있습니다.

## 실수했을 때

| 상황 | 해결 |
|---|---|
| 개인 파일을 잘못 올렸다 | **저장소를 즉시 삭제**하세요. Settings 맨 아래 *Delete this repository*. 파일만 지우면 기록에 남습니다 |
| 폴더가 한 겹 더 들어갔다 | 파일들을 지우고 다시 올리거나, 저장소를 지우고 처음부터 |
| 공개로 만들었다가 되돌리고 싶다 | Settings → *Change repository visibility* → Private. 단, 그 사이 누가 복사했을 수 있습니다 |
| `python3: command not found` | 윈도우는 `python` 으로 시도. 안 되면 Python 재설치 시 "Add Python to PATH" 체크 |
