# Claude 활용 3모드 계획

작성 기준일: 2026-08-14

---

## 0. 세 모드를 한 문장으로

| 모드 | 정체 | 성공의 정의 |
|---|---|---|
| **직장인모드** | 회사의 쇼핑몰·오픈마켓 제작/운영 | 남이 3일 걸리는 일을 반나절에 끝내는 사람이 된다 |
| **백수모드** | 퇴사를 전제로 한 개인사업 준비 | 퇴사일에 "0부터 시작"이 아니라 "이미 돌아가는 것"을 갖고 나온다 |
| **엄마모드** | 재수생·고2 두 아들 입시 | 정보 부족이나 일정 사고로 기회를 잃지 않는다 |

세 모드는 경쟁 관계가 아닙니다. **직장인모드가 백수모드의 재료를 만들고, 엄마모드가 마감을 강제합니다.**

## 1. 활용 순서 — 왜 이 순서인가

### 1순위 · 엄마모드 (지금 당장, 8~12월)

**시간이 되돌아오지 않는 유일한 영역이기 때문입니다.**

2027학년도 일정은 대략 이렇게 흘러갑니다 (정확한 날짜는 평가원·각 대학 공고로 반드시 확인):

```
8월 중순   ← 지금.   모집요강 확정본이 나와 있는 시기
9월 초             수시 원서접수 (6장 확정 — 되돌릴 수 없음)
10월               수능 전 논술 일부
11월 중순          수능 (11/19 유력, 공고 확인)
11월 말~12월 초    수능 후 논술·실기 집중 — 여기서 일정 충돌이 터짐
12월~1월           정시 / 고2는 다음 사이클 시작
```

지금은 **원서접수 약 3주 전**입니다. 6장 조합을 계산해 볼 수 있는 마지막 여유 구간이고,
9월에 원서를 넣고 나면 일정 충돌은 계산의 문제가 아니라 포기의 문제가 됩니다.
그래서 이 계획의 첫 결과물로 `nonsul-timetable` 스킬을 먼저 만들었습니다.

### 2순위 · 직장인모드 (상시, 매일)

회사 일은 **매일 반복되고, 실패해도 복구 가능하며, 실력이 남습니다.**
Claude를 붙일 때 학습 비용 대비 회수가 가장 빠른 곳이라 실전 훈련장으로 씁니다.
여기서 손에 익힌 것이 그대로 3순위의 자산이 됩니다.

### 3순위 · 백수모드 (누적, 별도 시간 거의 안 씀)

**따로 시간을 내서 준비하는 게 아니라, 1·2순위의 부산물을 모으는 방식으로 굴립니다.**
퇴근 후에 사업을 또 하려 들면 셋 다 무너집니다.
대신 회사에서 한 일마다 "이건 내 것으로 가져갈 수 있나?"를 한 줄씩 기록해 둡니다.

> **경계선 —** 회사의 코드·데이터·계정·거래처 정보는 회사 것입니다. 가져 나올 수 없고, 가져 나오면 안 됩니다.
> 가져 나올 수 있는 건 **방법론**입니다. 상세페이지 만드는 순서, 오픈마켓 등록 체크리스트,
> 반복 작업을 자동화한 스킬의 구조 — 이건 회사 자산이 아니라 본인의 역량입니다.
> 개인사업 준비 작업은 회사 시간·회사 장비와 분리해서 하세요. 이 구분만 지키면 나머지는 전부 안전합니다.

## 2. 모드별 활용 방법

### 🏢 직장인모드 — 쇼핑몰·오픈마켓 제작/운영

**Claude에게 시킬 일 (효과 큰 순서)**

1. **상세페이지 제작 파이프라인**
   상품 정보 → 카피 초안 → HTML 상세페이지 → 이미지 배치. 이미 `단장(丹粧)` 프로젝트에서
   쇼핑몰 페이지를 파싱하는 코드(`lib/extract.js`)를 만들어 봤으므로 그 구조를 그대로 재활용합니다.
2. **오픈마켓 멀티 등록**
   스마트스토어·쿠팡·11번가·지마켓은 상품명 규칙, 카테고리, 옵션 형식이 전부 다릅니다.
   마켓별 변환 규칙을 스킬로 고정해 두면 상품 1개 등록이 4개 등록이 됩니다.
3. **정산·매출 정리**
   각 마켓 정산 엑셀을 하나로 합쳐 상품별 실마진(수수료·배송비·반품 반영)을 뽑습니다.
   → `xlsx` 스킬 사용.
4. **CS 응대 템플릿**
   반복 문의 유형을 분류하고 답변 틀을 만듭니다. 개인정보가 든 원본은 넣지 말고 유형만 다룹니다.
5. **경쟁사·키워드 리서치**
   WebSearch로 카테고리 상위 노출 상품의 상품명 패턴을 뽑아 네이밍 규칙을 만듭니다.

**만들 자산 (`.claude/skills/`)**
- `product-detail` — 상품정보 → 상세페이지 HTML
- `market-listing` — 마켓별 상품 등록 데이터 변환
- `settlement` — 정산 엑셀 통합·마진 계산

**안 할 일** — 회사 실계정 자동 로그인/자동 등록 매크로. 마켓 약관 위반 소지가 있고 계정 정지 리스크가 본인에게 옵니다. 데이터 가공까지만 자동화하고 최종 업로드는 사람이 누릅니다.

### 🌱 백수모드 — 개인사업 준비

**핵심 원칙: 준비의 결과물은 "계획서"가 아니라 "돌아가는 것"입니다.**

퇴사를 앞둔 사람들이 가장 많이 하는 실수가 사업계획서를 쓰는 겁니다.
계획서는 팔리지 않습니다. 작게라도 실제로 돌아가는 것 하나가 계획서 열 장보다 낫습니다.

**단계**

| 단계 | 기간 | 산출물 |
|---|---|---|
| ① 자산 목록화 | 1개월 | 내가 할 줄 아는 것 / 가진 것 / 아는 사람 을 문서 1장 |
| ② 후보 아이템 3개 | 2개월 | 각각 "누가 왜 돈을 내는가" 한 문단씩 |
| ③ 최소 실험 | 3~6개월 | 랜딩페이지 + 실제 판매 시도 1회 (매출 0원이어도 됨) |
| ④ 숫자 확인 | 6~9개월 | 원가·수수료·배송비 넣은 손익 시뮬레이션 |
| ⑤ 퇴사 조건 정의 | 9~12개월 | "월 매출 N원 / 현금 M개월치 확보 시 퇴사" 를 숫자로 |

**⑤가 이 모드의 진짜 결론입니다.** 퇴사 시점을 기분이 아니라 숫자로 미리 정해 두면,
회사가 힘든 날의 충동 퇴사도, 두려움 때문에 놓치는 타이밍도 둘 다 막힙니다.

**Claude 활용**
- 아이템별 시장 조사 → WebSearch + 요약
- 랜딩페이지 제작 → `단장`처럼 정적 웹앱으로 빠르게. 이미 해봤습니다.
- 손익 시뮬레이터 → `xlsx` 스킬로 스프레드시트
- 사업자등록·통신판매업 신고·부가세 같은 행정 절차 → 체크리스트로 정리
  (단, 세무·법률 최종 판단은 세무사에게. Claude는 질문 목록을 만들어 주는 역할)

**`단장(丹粧)` 프로젝트의 위치** — 이건 이미 백수모드 자산입니다.
회사 데이터 없이 혼자 만든 것이고, 쇼핑몰 도메인 지식이 들어 있고, 데모가 돌아갑니다.
③ 최소 실험의 후보 1번으로 두세요.

### 👩‍👦‍👦 엄마모드 — 두 아들 입시

**두 아이는 전혀 다른 트랙입니다. 섞으면 둘 다 놓칩니다.**

| | 첫째 (재수생) | 둘째 (고2, 영화과) |
|---|---|---|
| 목표 연도 | 2027학년도 | 2028학년도 |
| 지금 국면 | **실행** — 9월 원서, 11월 수능, 12월 논술 | **탐색** — 학교·전형 구조 파악, 포트폴리오 |
| 이번 시즌 과제 | 논술 6장 조합 확정 | 영화과 전형 유형 이해 + 작업물 쌓기 |
| 리스크 | 일정 충돌로 카드 낭비, 수능최저 미충족 | 실기·포트폴리오 준비를 고3에 시작하는 것 |

**첫째 — 지금부터 12월까지**

1. 후보 대학을 `mom-mode/2027-논술후보.csv` 에 모읍니다 (날짜는 각 대학 입학처 모집요강에서만).
2. `nonsul-timetable` 스킬로 충돌 검사 → 6장 조합 확정 → 9월 원서접수.
3. 수능최저 충족 가능성을 냉정하게 `Y/N/?` 로 표시합니다. `N`인데 넣는 카드는 사실상 5장짜리 지원입니다.
4. 수능 후 논술 주간은 `--ics`로 캘린더에 넣고 **입실 마감 기준**으로 알림을 겁니다.

**둘째 — 지금부터 1년**

영화과는 대학마다 요구하는 게 완전히 다릅니다. 수능 위주, 실기(스토리텔링/영상제작), 포트폴리오, 면접 —
**"영화과"라는 하나의 준비법은 없습니다.** 그래서 순서가 이렇습니다.

1. **전형 유형 지도부터** — 목표 대학 5~8곳의 영화·영상 관련 학과를 뽑아
   `mom-mode/2028-영화과-전형지도.md` 에 [수능 반영 / 실기 유무 / 실기 종류 / 포트폴리오 요구 / 면접] 표로 정리.
   여기서 "우리 아이가 갈 수 있는 길"이 3~4개로 좁혀집니다.
2. **좁혀진 길에 맞춰 고2 하반기~고3 상반기에 뭘 쌓을지** 역산합니다.
   단편 영상이든 시나리오든, **완성된 결과물의 개수**가 실력보다 먼저입니다.
3. 고3 때는 첫째와 똑같이 `nonsul-timetable` 로 실기·면접 일정을 짭니다.
   실기는 3~4시간짜리라 논술보다 충돌이 훨씬 잘 납니다. 이 스킬이 더 크게 쓰일 곳입니다.

**엄마모드에서 Claude를 믿으면 안 되는 것**
- **시험 날짜와 모집인원.** 반드시 대학 입학처 원문으로 확인합니다. 커뮤니티 요약은 옛날 정보가 섞입니다.
- **합격 가능성 예측.** 하지 않습니다. Claude가 할 수 있는 건 일정 충돌 계산과 정보 정리까지입니다.

## 3. 공통 인프라

### 폴더 구조

```
mom_ai/
├── .claude/skills/          # 반복 작업을 스킬로 고정 (모드 공용)
│   └── nonsul-timetable/    #   ✅ 완성 — 논술·실기 일정 충돌 해결
├── plans/                   # 이 문서
├── mom-mode/                # 입시 자료 (아이별 CSV·전형지도)
├── work-mode/               # 회사 업무 산출물
├── solo-mode/               # 개인사업 준비 (아이디어·손익·랜딩)
└── (단장 앱 — 현재 루트)     # 백수모드 실험 1호
```

### 스킬을 만드는 기준

**같은 일을 세 번째 하게 되면 그때 스킬로 만듭니다.** 미리 만들지 않습니다.
한 번 하고 만들면 안 쓰는 스킬이 쌓이고, 다섯 번 하고 만들면 이미 지쳐 있습니다.

### 기록

각 모드 폴더에 `LOG.md` 하나씩. 하루 한 줄이면 충분합니다.
백수모드의 재료는 이 로그에서 나옵니다.

## 5. 한 가지만 기억한다면

세 모드 중 **되돌릴 수 없는 것은 엄마모드뿐입니다.**
회사 일은 내일 다시 할 수 있고, 사업 준비는 1년 늦어도 됩니다.
아이들의 이번 입시는 다시 오지 않습니다. 충돌이 나면 우선순위는 항상 여기입니다.
